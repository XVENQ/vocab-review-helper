## 输入

## 输出
每页写**一个**文件：`C:/Users/xuenc/Desktop/wokBuddy/背词助手/docs/exam_vocab/raw/page_{PPP}.md`
`PPP` = 分配给你的页号（两位或三位，如 `page_015.md`）。**文件名用分配号，`printed` 字段填你从纸上读到的印刷页码**——两者不一致时以你读到的为准，并在 `SKIP` 里写 `page_mismatch: 分配015 实读016`。

文件格式（严格照抄结构，不要加任何额外说明行）：

```
---
page: 15
printed: 15
img: img08_L.png
quality: ok
---
TITLE: 页眉或本节标题（如 Part VI Writing (20 points)）；没有就写 none
BODY:
<<<
正文逐字
>>>
STATS: words=312 paras=5 suspects=0
SUSPECTS: none
SKIP: none
```

## 抄录硬规则

1. **逐字抄录**：保留原始拼写、标点、单复数、时态。**看到语法错误也不要改**——这是改错题的素材（如 `She didn't finish the task on time` 这类就是原题）。
2. **禁止任何标记语言**：不要 `<u>`、`**`、`_强调_`、表格竖线。纯文本，一行一句/一段。
3. **原题里的下划线**（改错题被划线的部分）用普通文字照抄，不要加符号；被划线的 A B C D 选项行照原样放在下一行。
4. **题号照抄**：`66.` `67.`；选项 `A.` `B.` `C.` `D.` 各占一行。**四行必须齐**（最常漏 D）。
5. **中文行**：行首加 `[ZH] `，例如 `[ZH] 56. 卡特是这三个女孩中最小的一个。`
6. **页眉/页脚**：页眉写进 `TITLE`；页码（`— 15 —`）**不要抄进正文**。
7. **不要抄**：二维码、条形码、水印、"视频讲解"角标、背面透印的鬼影字（灰底反向字）。
8. **专名保留原样**：Wensu / Gezhouba / Taobao / DeepSeek，不要"纠正"。
9. **认不出**：单词写 `word[?]`，整句写 `[??]`。**绝对不许根据上下文猜词**。
10. 段落之间空一行；表格类内容（分值表）按行抄，用制表符或空格分隔均可，**不要画竖线**。

## 质量判定
- `[?]` 出现 ≤ 3 且不影响阅读 → `quality: ok`
- `[?]` 超过 8 个，或整段发虚 → `quality: low`（**仍然照常转录，能读多少抄多少**）

- 选项行有没有漏 D？
- 页脚页码与你填的 `printed` 一致吗？
