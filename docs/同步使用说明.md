# 背词助手 · 手机 + 电脑局域网同步使用说明

## 一、它是什么

电脑上跑一个小型同步服务器（纯 Python 标准库，零依赖），管着那份 `背词助手数据.json`。
手机浏览器打开电脑的地址，用**同一份数据**：

```
手机背单词（离开电脑、无网都行）
   → 进度暂存手机浏览器本地
回到电脑旁（手机热点 / 家里 WiFi，同网即可）
   → 打开页面自动「按词合并」，两边的进度都保留
```

- **冲突策略是按词合并**：两边各背的词都保留；同一个词两头都背过，取最近背的那条记录
- 删词会以「墓碑」形式同步，不会在另一头复活
- 服务器每次写盘前自动备份（保留最近 30 份），出问题随时可回

## 二、电脑端：启动服务器

**日常方式（推荐）：双击桌面的「启动背词同步.bat」**——自动启动服务器、弹出二维码图片、打开电脑端页面。

也可以手动跑：

```
cd C:\Users\xuenc\Desktop\wokBuddy\背词助手
python tools\sync_server.py
```

启动后会打印：
- 手机访问地址（形如 `http://192.168.x.x:8765/`，热点网段每次可能变，以打印为准）
- **终端二维码 + 自动弹出的大图二维码**（`%TEMP%\beici_qr.png`），手机扫一下即可进入
- 本机自动打开页面（电脑也可以直接用这个地址背）

## 三、第一次使用：放行防火墙（只需一次，需管理员）

手机连不上时，用**管理员身份**运行：

```
netsh advfirewall firewall add rule name="BeiciSync" dir=in action=allow protocol=TCP localport=8765
```

（手机热点网络在 Windows 里通常判为「公用」，入站默认被拦——这是手机访问不通时的第一排查项。）

## 四、手机端：怎么用

**一次配置（之后就不用记地址了）：**

1. 电脑双击「启动背词同步.bat」，等二维码弹出来
2. 手机浏览器**扫码**进入页面
3. 浏览器菜单里点「**添加到主屏幕**」（Chrome/Edge：右上角 ⋮ → 添加到主屏幕/添加到主界面）
4. 以后手机桌面上就有一个「背词助手」图标，点开直达，地址完全不用记

**日常使用：**

1. 手机开热点（或与电脑连同一 WiFi）
2. 点桌面的「背词助手」图标（第一次或换了网络后用扫码）
3. 页面会显示「同步：已连接 · 共 N 词」——至此手机和电脑是同一份数据

> **主屏图标记住的是创建时的地址。** 手机热点和家里 WiFi 的网段不同、电脑 IP 变了时，图标可能打不开——此时重新扫一次码即可（扫码本身就是应对换网的手段）。Android 热点下电脑 IP 基本固定，多数情况不用重扫。

## 四·五、离线副本：不在同一网络也能背

电脑页面顶部有一个「**下载离线副本**」按钮（连接服务器后出现）。点它会把整个应用存成手机里的一个 HTML 文件：

- **离开局域网后，从手机的「文件/下载」里打开这个文件就能背**——不需要网络，进度存手机本地
- 副本里已注入服务器地址：**回到同一网络时打开副本，会自动连上电脑合并同步**，状态栏显示「离线副本模式」
- 连不上时它会安静地当纯离线用，什么都不会丢

注意：

1. 副本和网页是**两份各自的本地缓存**，建议固定用一种方式背（推荐副本，它离线在线都能用）
2. 电脑 IP 变了之后，旧副本找不到家——连上网络后在**网页版**点一次「下载离线副本」覆盖旧的即可
3. 副本清不掉学习记录风险同前：别用手机管家「深度清理」扫掉浏览器/下载的数据

之后正常背单词即可：
- 每次答题约 2 秒后自动推送；离开网络时改动存在手机本地，状态栏会提示「服务器不可达，改动已存本机」
- 回到同网后刷新页面（或点「同步」按钮），离线期间的进度自动合并

## 五、注意与限制

| 事项 | 说明 |
|---|---|
| 固定用同一个手机浏览器 | 进度暂存在浏览器的 localStorage 里，**换浏览器 = 换一份空白本地缓存**（连上服务器后会自动合并回来，但离线期间的新进度只在那一个浏览器里） |
| 电脑端两种模式别混用 | `http://localhost:8765/`（服务器模式，推荐）与双击打开的 file:// 文件模式都能用，但**同一时间段只用一种**。file:// 模式删词不产生同步标记 |
| 服务器要开着 | 同步发生的前提是电脑在跑 `sync_server.py`。电脑关机时手机照常背，回网后再同步 |
| 离线很久才回来 | 没问题，按词合并会补齐；但离线期间手机本地是唯一副本，别清浏览器缓存 |
| 导入新词 | 在哪端导入都行，按词合并会同步到另一端（同 id 撞车会自动重编号） |

## 六、常见问题

**手机打开是空白/提示同步服务器不可达**
→ 电脑没开服务器，或不在同一网络，或防火墙没放行。按顺序查：服务器开着吗 → 同一网段吗 → 防火墙命令执行了吗。

**电脑端 file:// 打开旧页面想切到同步模式**
→ 直接用浏览器访问 `http://localhost:8765/` 即可，数据文件是同一份。

**数据坏了怎么回滚**
→ `wokBuddy\背词助手\backups\sync\` 里是服务器每次写盘前的自动备份；把对应文件覆盖回
`C:\Users\xuenc\Desktop\英语学习方法\studyEnglish\背词助手数据.json`，刷新页面即可（服务器会检测到外部改动并收编）。
