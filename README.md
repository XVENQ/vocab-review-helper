# 背词助手

**单文件 HTML 的间隔重复（SRS）背单词工具。双击即用，不需要安装、不需要联网、没有后端。**

针对的是一类具体需求：单词已经按词群在书上或课堂上"学过"一遍了，之后**复习怎么排、每天复习哪些、哪些词老是记不住**——这些交给程序，而不是靠自觉。

---

## 特性

| 模块 | 说明 |
|---|---|
| **间隔重复排期** | 成熟阶梯 1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天，按四档评分自动推进 |
| **四档评分** | 重来 / 困难 / 良好 / 简单（空格翻面，1–4 评分），评「重来」当天再考 |
| **批次乱序** | 按批次导入，复习时**跨批次打乱**，防止同族词互相干扰 |
| **每日上限** | 默认 40 张，超出自动顺延不堆积；上限可改，改完立即重算今日清单 |
| **内置词库 21329 词** | 导入时只填英文，释义自动查；查不到会标「释义待补」 |
| **英式 DJ 音标** | 全库统一为非儿化、ɒ/ɔː 分化的 DJ 体系，与国内教材一致 |
| **发音** | 卡片上点 🔊 或按 `P`；英式/美式可切，失败自动降级系统语音 |
| **单词计时** | 卡片出现→评分自动计时，累计到每个词；顶部看总时长与今日，词库看单词耗时 |
| **顽固词** | 错 ≥2 次的词单独成表，可一键抽出来短间隔强化 |
| **生词预习** | 错 ≥2 次的词，每天第一次出现时**直接给释义和例句**（学习模式），点「记住了」才进入考试模式 —— 不给零记忆的词制造无效挫败 |
| **顽固词提示** | 错 ≥2 次的词，卡住 12 秒先给英文例句，22 秒再给英文释义 / 构词拆分 / 谐音画面联想，不用直接看中文答案 |
| **故事复习** | 8 篇 100 词以内的短文，每篇只装 10–12 个目标词，读完再回看这些词；文中目标词点一下可听发音、看释义 |
| **数据双写** | 浏览器缓存 + 磁盘 JSON（File System Access API），清缓存/换电脑都不丢 |
| **每日快照** | 首次打开自动备份，保留 7 天，误操作可回滚 |

## 快速开始

1. 下载 `背词助手.html`
2. 用 **Chrome 或 Edge** 打开（双击即可，地址栏是 `file:///...`）
3. 首次进入点顶部「选择数据文件」，指定一个 `.json` 保存位置 —— 之后每次改动自动写入
4. 到「导入」页，每行贴一个英文单词，点导入
5. 第二天起，这些词会出现在「今日复习」里

> **为什么必须选数据文件**：`file://` 页面没有本地存储的长期保障，清缓存或换浏览器就丢。选一次文件后，学习记录就是一个普通 JSON 文件，可以自己复制、备份、换机器带走。

## 数据存哪儿

三层结构，互相兜底：

| 层 | 位置 | 作用 |
|---|---|---|
| localStorage | `cihui_review_v1` | 主数据副本，随改随写 |
| localStorage | `cihui_snapshots_v1` | 最近 7 天的日快照 |
| IndexedDB | `cihui/kv.dataHandle` | 磁盘文件句柄，记住上次选的文件 |
| 磁盘 | `背词助手数据.json` | **权威数据**，可自行备份迁移 |

`applyData()` 的合并规则是**比较 `updatedAt`，取较新的一份**。因此任何离线改数据的脚本都必须刷新 `updatedAt`，否则会被浏览器里的旧副本反向覆盖。

### 数据结构

```js
state = { words: [], settings: { maxReview, accent }, updatedAt, dayPlan: { date, ids }, todayTime: { date, ms } }

word = { id, word, meaning, phonetic, batch, added,
         step: 0..7, nextDate, lapse, lastRated,
         example, exampleZh, note, needMean, timeMs }
```

- `step` 是间隔阶梯的档位，`nextDate` 是下次出现的日期（**排期只认它**）
- `lastRated` 只用于抵扣当日名额，**不能拿来做筛选**（评「重来」时 `nextDate` 仍是当天，用 `lastRated` 过滤会让这些词集体消失）
- `timeMs` 是该词累计学习毫秒数；总时长由所有词求和得出，不单独存

## 怎么用才有效

这些是从实际数据里踩出来的，不是理论：

- **5 秒法则**：想 5 秒没头绪就翻答案。实测「死磕 30 秒」的卡片平均耗时 55 秒、重来率 90%——长挣扎不会让你记住，只会让你讨厌这个动作。
- **别默念释义，建一个钩子**：`receive = re(回) + ceive(拿) → 拿回来 → 收到`，越荒诞越跟自己有关越好。反复朗读是最浅的复述。
- **每天 15–20 张就够**：宁可少背，也不要带着挫败感离场。欠账会自己降下来，情绪崩了就不会再打开。
- **顽固词先预习再考**：对完全没建立联结的词，反复提取失败是无效的（空抽屉里取不出东西）。先看一遍，十几分钟后再考，才是记忆真正发生的窗口。

## 音标与发音

- **音标**：英式 DJ。由 CMU 发音词典的 ARPAbet 转写而来，规则包含非儿化、中元音合并（ɪə/eə/ʊə）、lot/thought 分裂（hot→ɒ，law→ɔː）、bath 分裂（ask→ɑːsk，cat→kæt）。
- **发音**：有道词典发音接口
  `https://dict.youdao.com/dictvoice?audio=WORD&type=1(英)/2(美)`，无需 Key。
  取不到时自动降级为浏览器 `speechSynthesis`（en-GB / en-US）；两条路都失败才提示错误。

## 工具脚本

`tools/` 下是配套的离线处理脚本，都是纯 Python（无第三方依赖）：

| 脚本 | 用途 |
|---|---|
| `build_dj_phonetic.py` | 从 CMUdict 生成 DJ 音标表（需要 `cmudict.dict` 与旧美式音标表） |
| `trim_meanings.py` | 按内置的 133 条映射，把词典级长释义压成考试义 |
| `export_words_md.py` | 把学习数据导出成按批次排列的 Markdown 词表 |

## 已知限制

- **只支持 Chrome / Edge**：依赖 File System Access API，Firefox、Safari 不行
- **单文件 1.9 MB**：词库全部内嵌，换来"双击即用、零依赖"，打开时会有一两秒延迟
- **多标签页同开不安全**：两个窗口会互相覆盖数据，同一时间只开一个
- 音标源自美式语料转写，个别多音节词的**主重音位置**可能与英式词典有出入
